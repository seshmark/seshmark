How it works

Install once

Run the install script. Seshmark adds a Git hook that auto-tags every commit. Zero config needed.

Use your AI tools

Work with cursor, claude, copilot, or any tool. Commits get tagged with AI-Agent, AI-Session, and AI-Model trailers automatically.

Query anytime

Run git agentblame to see who wrote each line. Query by agent, model, or file. Resume sessions. All from Git.

The Seshmark Convention

AI commits include Git trailers. It works even without the CLI installed.

Commit message 
feat: implement OAuth2 middleware

# Seshmark adds these automatically:
Seshmark-Version: 1.0.0
AI-Session: cursor:chat-abc123
AI-Agent: cursor
AI-Model: claude-sonnet-4-20250514
Branch inference 
# Working on a branch? Seshmark infers the agent.
# No env vars or config needed.

git checkout -b claude/auth-refactor

# Commits on this branch are automatically tagged:
AI-Agent: claude

# Works with any naming pattern:
cursor/fix-login
copilot/api-tests

Commands

Command What it does
git agentblame <file> Show which AI wrote each line
seshmark stats AI usage report by agent, model, and file
seshmark query [filters] Search AI-tagged commits
seshmark who [commit] Show agent, model, and session for a commit
seshmark context <commit> Reconstruct the session context
seshmark log <session> List all commits in a session
seshmark resume <session> Reopen the AI session that wrote the code
seshmark status Show active session
✓ Works with every AI coding harness
cursor claude copilot aider opencode pi + any tool that sets SESHMARK_* env vars

Built for the way you work

Zero Configuration

Install once. The Git hook auto-tags every commit made by any AI tool. No servers, no APIs, no config files — everything runs locally on your machine. Your data never leaves.

Tool Agnostic

Works with cursor, claude, copilot, aider, opencode, pi, and any tool that sets SESHMARK_* env vars. No vendor lock-in. Bring your own harness.

Git Native

The convention uses standard Git trailers. It works without Seshmark installed — just type the trailers by hand and everything still reads them.

Branch Inference

Working on claude/auth-refactor? Commits are auto-tagged AI-Agent: claude even without explicit session tracking.

Session Resumption

Found who wrote a line? Resume the exact session. seshmark resume HEAD opens the AI tool on the right conversation.

Orchestrator Ready

Every command supports --format json. AI agents can query, blame, and resume sessions programmatically.
