Seshmark

Agent-aware Git history. Know which AI wrote every line.

Also known as: git agentblame agentblame aiblame

Install
curl -fsSL https://seshmark.github.io/seshmark/install.sh | bash

Works on macOS, Linux, and WSL. One command. No dependencies.

Zero Configuration

Install once. The Git hook auto-tags every commit made by Cursor, Claude Code, Copilot, or any tool that sets SESHMARK_* env vars.

Branch Inference

Working on claude/feature-auth? Commits are automatically tagged with AI-Agent: claude even without explicit session tracking.

Tool Agnostic

No vendor lock-in. Works with Cursor, Claude Code, OpenCode, Codex, Aider, GitHub Copilot, or any future AI coding tool.

Orchestrator Ready

Every command outputs --format json. Autonomous agents can trace code back to its original session and resume or reconstruct context.

VS Code Extension

See [cursor], [claude] inline in your editor gutter. Hover for session details. Toggle on/off from the status bar.

Git Native

The convention works without any tool installed. Just add Seshmark-Version, AI-Session, AI-Agent trailers to commit messages by hand.
